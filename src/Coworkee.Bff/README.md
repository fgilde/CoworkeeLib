# Coworkee.Bff

Backend for frontend for Blazor WebAssembly: cookie session, token handling, API forwarding, the loading screen in the theme's colours and the installable app (web manifest, service worker, offline page).

Part of [Coworkee](https://framework.coworkee.de/), a modular application framework for .NET 10, Blazor and Aspire. Start a new app with the CLI:

```bash
dotnet tool install -g Coworkee.Cli
coworkee new MyApp
```

Or add the package to an existing one:

```bash
dotnet add package Coworkee.Bff
```
