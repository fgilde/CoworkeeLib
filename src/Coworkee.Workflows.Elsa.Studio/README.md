# Coworkee.Workflows.Elsa.Studio

Elsa Studio, the visual workflow designer, as an app of its own that signs in at the Coworkee auth server.

Part of [Coworkee](https://framework.coworkee.de/), a modular application framework for .NET 10, Blazor and Aspire. Start a new app with the CLI:

```bash
dotnet tool install -g Coworkee.Cli
coworkee new MyApp
```

Or add the package to an existing one:

```bash
dotnet add package Coworkee.Workflows.Elsa.Studio
```
