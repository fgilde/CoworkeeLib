# Coworkee.Infrastructure

CoworkeeDbContext on Postgres, SQL Server or SQLite with tenants, soft delete, field level audit trail and transactional outbox.

Part of [Coworkee](https://framework.coworkee.de/), a modular application framework for .NET 10, Blazor and Aspire. Start a new app with the CLI:

```bash
dotnet tool install -g Coworkee.Cli
coworkee new MyApp
```

Or add the package to an existing one:

```bash
dotnet add package Coworkee.Infrastructure
```
