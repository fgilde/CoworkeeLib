# Coworkee.EventBus

Integration events between apps and services through the transactional outbox, with an inbox for idempotent handlers. Works without a broker.

Part of [Coworkee](https://framework.coworkee.de/), a modular application framework for .NET 10, Blazor and Aspire. Start a new app with the CLI:

```bash
dotnet tool install -g Coworkee.Cli
coworkee new MyApp
```

Or add the package to an existing one:

```bash
dotnet add package Coworkee.EventBus
```
