# Coworkee.Aspire

AddCoworkeeApp() for the Aspire app host: migrations, auth server, APIs, workers and web wired with Postgres (or SQL Server, SQLite), Redis, Mailpit, Elasticsearch and Keycloak.

Part of [Coworkee](https://framework.coworkee.de/), a modular application framework for .NET 10, Blazor and Aspire. Start a new app with the CLI:

```bash
dotnet tool install -g Coworkee.Cli
coworkee new MyApp
```

Or add the package to an existing one:

```bash
dotnet add package Coworkee.Aspire
```
