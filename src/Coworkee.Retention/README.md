# Coworkee.Retention

Retention: how long logs, processed messages and deleted rows are kept, a nightly cleanup and an admin page to set the days and delete now.

Part of [Coworkee](https://framework.coworkee.de/), a modular application framework for .NET 10, Blazor and Aspire. Start a new app with the CLI:

```bash
dotnet tool install -g Coworkee.Cli
coworkee new MyApp
```

Or add the package to an existing one:

```bash
dotnet add package Coworkee.Retention
```
