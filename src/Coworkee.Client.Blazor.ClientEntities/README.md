# Coworkee.Client.Blazor.ClientEntities

Client entities for Blazor WebAssembly: mirror OData sets in the browser and filter, search, sort and facet them locally.

Part of [Coworkee](https://framework.coworkee.de/), a modular application framework for .NET 10, Blazor and Aspire. Start a new app with the CLI:

```bash
dotnet tool install -g Coworkee.Cli
coworkee new MyApp
```

Or add the package to an existing one:

```bash
dotnet add package Coworkee.Client.Blazor.ClientEntities
```
